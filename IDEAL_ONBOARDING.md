# Constant Contact Connector — Ideal Onboarding Flow

1. **Prerequisites:** Constant Contact Developer account and created Application or generated OAuth 2.0 Access Token.
2. **Setup:** Navigate to Imperal Cloud > Constant Contact Connector > Left Sidebar.
3. **Connection:** Paste the Access Token into the API Key input and click Connect.
4. **Validation:** System queries `GET /account/summary` to verify token validity and display connected account details.
